# Run Verification

This skill runs static analysis and tests to ensure no regressions have been introduced in the workspace.

## Usage

### 1. Run Static Analysis
Analyze code for errors and warnings:
```powershell
flutter analyze
```

### 2. Run Tests
Run all unit, widget, and mock-based regression tests:
```powershell
flutter test
```
